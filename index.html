UTS · Advanced ML · Oct 2026

Crypto trend forecasting API

My service in a four-service crypto analytics platform. An XGBoost classifier predicts a token's trend 7 days ahead, from Strong Downtrend to Strong Uptrend, for 8 tokens using daily Kraken market data.

The twist: it depends on two teammates' APIs, so I trained it with simulated outages. It calls both peers in parallel with a timeout and still predicts when one goes down.

All up0.416
A down0.422
B down0.363
Both down0.293

Macro-F1 on the test period. 60 Optuna trials × 3 walk-forward folds.
